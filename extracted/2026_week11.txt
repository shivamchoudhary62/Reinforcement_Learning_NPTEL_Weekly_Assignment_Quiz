1. Which of the following option is correct for the sub-task terminations in the MAXQ Frame-
work?
(a) The termination is stochastic
(b) The termination is deterministic
Sol. (b)
As discussed in the lectures, for each sub-task, all states of the core MDP are partitioned into
a set of active states and a set of terminal states, where sub-task termination is immediate
(and deterministic) whenever a terminal state is entered.
